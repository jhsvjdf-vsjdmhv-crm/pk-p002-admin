# PK-P002 Admin Management System (Mast Loan)

Professional loan collection and customer management admin console for Mast Loan (PK-P002).

## Features
- **Customer Order & KYC Management**: View order details, borrower basic info, loan amounts, overdue tracking, bank details, and identity verification documents (Live Portrait and PAN Card).
- **Repayment Records & Collections**: Inspect past partial payments and add new collection notes with real-time state updates.
- **Multi-Tab Navigation**: Switch between **Order Information**, **Customer Message**, and **Contact List**.
- **Interactive Action Modals**: Send partial repayment reminders, copy payment links to clipboard, and dispatch extension links.
- **Local Dev Setup Guide**: Built-in instructions and instructions for running locally.

---

## Local Development & Setup

Follow these steps to run the project locally for testing and development:

### Prerequisites
- Node.js (v18 or higher)
- Git

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/mdnahidul112nd-art/pk-p002-admin.git

# 2. Navigate into project directory
cd pk-p002-admin

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

### Production Build
```bash
npm run build
```
